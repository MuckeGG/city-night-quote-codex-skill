# 来源、版权与标识

## 来源台账

`source-ledger.csv` 至少记录：

`source_name, source_url, title, published_at, author, exact_excerpt, usage_mode, rights_status, checked_at`

`usage_mode` 使用 `short_excerpt`、`paraphrase` 或 `licensed_quote`；`rights_status` 使用 `unverified`、`editorial_test`、`licensed` 或 `original`。

## 使用策略

- 只引用可以打开并核对的官方页面。
- 不把媒体名称当作授权证明。
- 未确认授权时，前期只用一条短摘录并明确来源；商业化内容默认改原创转述或使用已授权文本。
- 不修改摘录原意，不拼接多篇文章制造不存在的原句。
- 不抓取和朗读完整文章，不搬运原视频或原图。

## AI标识

输出包中固定加入：

`AI生成画面：本视频部分城市场景由人工智能生成，仅作氛围表达。`

发布到平台时主动使用平台的AI生成标识，不删除生成工具或平台添加的隐式标识。
